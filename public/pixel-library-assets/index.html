Drawing order

  1. library_bg.png draws the room, tables, lamps and empty chairs.
  2. Far-seat avatars come next, using frames 0–3 (facing you).
  3. Near-seat avatars use frames 4–7 (back view). Then draw chair_near.png again on top, so the backrest sits in front of them.
  4. lighting_overlay.png goes over everything, then bubbles and name tags.
  5. Every coordinate lives in layout.json, in native pixels. Scale the canvas with image-rendering: pixelated.
